Deploy to GKE, AKS & EKS

Push fine-tuned models to any managed Kubernetes cluster with one command. Auto-generated manifests, GPU node pools, vLLM inference servers, and HPA autoscaling — out of the box.

Google GKE container.googleapis.com

Autopilot or Standard clusters with L4 / A100 / H100 node pools and Filestore-backed model caching.

$ ai-core deploy --target gke --cluster ai-prod-us-central1 --node-pool a100-80gb --replicas 3 # → gke.ai-core/ai-prod-us-central1 created
  • Runtime: containerd + gVisor
  • Ingress: Global LB + Cloud Armor
  • Autoscale: HPA + NAP (node auto-provisioning)
Azure AKS management.azure.com

GPU-enabled node pools with Azure CNI Overlay, Workload Identity, and Azure ML–linked registries.

$ ai-core deploy --target aks --cluster ai-foundry-prod --node-pool nc24ads-a100 --replicas 3 # → aks.ai-foundry-prod connected
  • Runtime: containerd + Kata Containers
  • Ingress: App Gateway + WAF
  • Autoscale: Cluster Autoscaler + KEDA
AWS EKS eks.amazonaws.com

Managed node groups with p4d / p5 instances, Karpenter autoscaling, and Bedrock endpoints via IRSA.

$ ai-core deploy --target eks --cluster ai-prod-us-east-1 --node-pool p5.48xlarge --replicas 3 # → eks.ai-prod-us-east-1 ready
  • Runtime: containerd + Firecracker
  • Ingress: ALB + AWS WAF
  • Autoscale: Karpenter + HPA
